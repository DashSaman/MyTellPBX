# میز کار و تحلیل گفتار در نامزد MytelPBX ۷٫۷٫۰

لایهٔ افزودهٔ مای‌تل، **پس از موفقیت راه‌اندازی بومی مرکز تلفن و رمزها**،
نصاب قفل‌شدهٔ **MytelDesk 1.1.3** را اجرا می‌کند. هش آرشیو، commit و tree
دقیق در [myteldesk-release.json](../installer/myteldesk-release.json) ثبت شده‌اند.
مسیر میز کار `https://pbx.example.com/MytellDesk/` است؛ دامنهٔ مثال را جایگزین کنید.

این نسخهٔ MytelPBX نامزد انتشار است. دامنهٔ قبولی نصب و تماس فقط با
[رسید نهایی ۷٫۷٫۰](releases/7.7.0/verification.md) مشخص می‌شود؛ وجود نسخهٔ
قفل‌شده یا اجرای doctor به معنی قبولی یک تماس واقعی نیست.

## محیط VAD و تنظیمات

نصاب مستقل میز کار، محیط Python 3.11، وابستگی‌های دارای هش و مدل VAD روی
CPU را آماده و بررسی می‌کند. لایهٔ MytelPBX همان نصب‌کننده و doctor محصول
را فراخوانی می‌کند. Python سیستم بومی، تنظیمات موجود ضبط و سیاست نگهداری
فایل‌ها حفظ می‌شوند؛ نصب موتور VAD، ضبط همهٔ تماس‌ها را فعال نمی‌کند.

برای دامنهٔ HTTPS مشخص، پیش از اجرای نصاب آنلاین مقدار
`MYTELL_DESK_PUBLIC_URL=https://pbx.example.com` را تنظیم کنید. بدون این
گزینه، نصاب میز کار نشانی مناسب سرور را انتخاب می‌کند. گواهی معتبر دامنه و
دسترسی میکروفن مرورگر باید برای محیط مقصد آماده باشند؛ این گزینه گواهی صادر
نمی‌کند و داخلی یا ترانک نمی‌سازد.

در ISO بومی، انبار تکمیلی مهرشده منابع محلی لازم را به همان نصاب میز کار
می‌دهد. نصب هستهٔ PBX و پنجره‌های رمز همچنان متعلق به ISO اصلی و اولین
راه‌اندازی بومی هستند. راهنمای [نصب فارسی](INSTALL.fa.md) و
[Installation guide](INSTALL.en.md) دامنهٔ هر مسیر را توضیح می‌دهند.

## ورود و بررسی

دکمهٔ میز کار در پنل، مجوز حساب را از ACL بررسی و کاربر را به نشانی ثابت
میز کار هدایت می‌کند. نشست موجود میز کار ادامه می‌یابد. برای ورود اولیه،
گزینهٔ «حساب پنل» را انتخاب و اطلاعات حساب مجاز پنل را وارد کنید؛ هدایت
لانچر ورود پنهانی با رمز مشترک مدیر یا ارسال توکن در URL نیست.

حساب محلی مدیر میز کار جداگانه است و اطلاعات اولیهٔ خصوصی دارد. فقط root
می‌تواند آن را بخواند:

```bash
cat /etc/myteldesk/initial-admin.txt
myteldesk doctor
```

doctor سرویس و اجرای مدل را بررسی می‌کند. ثبت SIP، صدای دوطرفه، اتصال داخلی
مرورگر و VAD خودکار روی تماس ضبط‌شده آزمون‌های جداگانه‌اند. داخلی‌ها و
سیاست ضبط را برای سناریوی موردنظر آماده کنید.

## مرز نصب و بازیابی

نصاب آنلاین پایه فقط برای **Rocky Linux 8.10 Minimal تازه** است. آن را برای
ارتقای PBX موجود یا ادامهٔ دلخواه یک پایهٔ نیمه‌راه‌اندازی‌شده اجرا نکنید.
پس از خطای لایهٔ افزوده، اطلاعات بومی، وضعیت میز کار و رسید بازیابی خصوصی
را حفظ کنید؛ مسیر رسید و پشتیبان‌ها هنگام اجرا چاپ می‌شود. پشتیبان لایهٔ
افزوده در `/var/backups/mytellpbx/native-addons/` است.

نصاب مستقل میز کار فقط نسخه‌ها و شناسه‌های سورس شناخته‌شده را مطابق
پروندهٔ انتشار می‌پذیرد؛ سورس متفاوت با شمارهٔ یکسان یا نسخهٔ جدیدتر، مجوز
بازنویسی خودکار نیست. این سازگاری محدود، مجوز اجرای نصاب کامل سیستم‌عامل
روی مرکز تلفن موجود نیست. نصب قدیمی `/opt/opdesk` نیز به بررسی مستقل داده،
کاربران و پراکسی نیاز دارد.

برای نگهداری خود میز کار، [راهنمای محصول مستقل](https://github.com/DashSaman/MytelDesk#readme)
و رسیدهای همان نصب مرجع هستند. گزارش‌های نسخه‌های قدیمی شواهد تاریخی‌اند
و جای رسید نهایی نامزد جاری را نمی‌گیرند.
