# نصب MytelPBX ۷٫۶٫۲

## نصب با یک خط

در ترمینال تعاملی یک سرور **راکی لینوکس ۸٫۱۰ تازه، x86_64** با دسترسی root و
اینترنت به مخازن رسمی و دارایی‌های انتشار اجرا کنید:

```bash
curl -fsSL -o install-mytellpbx.sh https://github.com/DashSaman/MyTellPBX/releases/download/v7.6.2/install-mytellpbx.sh && bash install-mytellpbx.sh
```

نشانی دریافت روی `v7.6.2` ثابت است و نصاب پیش از استفاده، هش بسته را بررسی
می‌کند. پیش از استفاده، [دامنهٔ بررسی نسخه](releases/7.6.2/verification.md) را
بخوانید؛ تکمیل نصب سرد نهایی یا آزمون واقعی صدای تماس برای این انتشار تأیید نشده است.

## پیش‌نیاز و دامنهٔ نصب

- راکی لینوکس ۸٫۱۰ دقیقاً، معماری x86_64؛ نسخهٔ Minimal مناسب است.
- سرور تازه، بدون نصب قبلی PBX
- دسترسی root و HTTPS به مخازن بسته‌ها، GitHub، nodejs.org،
  files.pythonhosted.org و فراهم‌کنندگان دادهٔ کشورها
- کف کنترل اولیه، ۸ گیگابایت فضای آزاد و حدود ۱٫۵ گیگابایت RAM است؛ این اعداد
  تضمین ظرفیت میز کار، VAD یا بار تماس محیط عملیاتی نیستند.
- نصاب کامل فقط **استریسک ۲۰** را نصب می‌کند؛ اجرای جاری و آزمون صدای
  استریسک ۱۶ و ۱۸ برای این انتشار تأیید نشده‌اند.

MariaDB، Apache، PHP 7.4، چارچوب ماژول‌های مرکز تلفن، قالب مای‌تل و
MytelDesk 1.1.2 با بررسی هش نصب می‌شوند. ناوبری فارسی پنل و میز کار راست‌چین
است؛ فرم‌های فنی PBX چپ‌چین می‌مانند. وجود ماژول به معنی آزموده شدن تمام
سناریوهای صف، فکس، ترانک و اتصال‌های بیرونی نیست.

## رمزها

ابتدای نصب، رمز کاربر `admin` پنل و رمز ریشهٔ MariaDB در **دو ورودی مخفی**
پرسیده می‌شود. Enter خالی برای هر مورد یک مقدار تصادفی می‌سازد.
نویسه‌های مجاز فقط ASCII هستند: `A-Z`، `a-z`، `0-9`، فاصله و `. @ = _ ! -`.
حروف فارسی برای رمز این مبدل بومی پذیرفته نمی‌شوند.

رمزهای پذیرفته‌شده در فایل مخصوص root با سطح دسترسی ۰۶۰۰ ذخیره می‌شوند:

```text
/root/mytelpbx-credentials.txt
```

رمزهای یکتا انتخاب کنید و فایل رمزها و گزارش نصب را خصوصی نگه دارید.
ادامهٔ مجاز همان انتشار، رمز ذخیره‌شده را بازنشانی نمی‌کند. در اجرای بدون
ترمینال، مقدارهای تعیین‌نشده تولید می‌شوند. نمونهٔ مقداردهی قبلی با جای‌نگهدار ASCII:

```bash
MYTELL_ADMIN_PASS='REPLACE_WITH_UNIQUE_ADMIN_PASSWORD' MYTELL_MYSQL_ROOT_PASS='REPLACE_WITH_UNIQUE_DATABASE_PASSWORD' bash install-mytellpbx.sh
```

## پنل، میز کار و ضبط

پس از موفقیت، نشانی چاپ‌شدهٔ `https://<server-ip>/` را باز کنید و با `admin`
و رمز پنل وارد شوید. گواهی تازه، خودامضا و شامل نام و نشانی‌های شناسایی‌شدهٔ
سرور است؛ مرورگر به‌صورت خودکار به آن اعتماد نمی‌کند. جفت گواهی/کلید معتبر
موجود حفظ می‌شود. برای استفادهٔ عمومی، گواهی معتبر دامنه را آماده کنید.

میز کار در `/MytellDesk/` قرار دارد. گزینهٔ **حساب پنل** از حساب مجاز پنل
استفاده می‌کند. مدیر محلی مستقل میز کار، رمز جداگانه‌ای در
`/etc/myteldesk/initial-admin.txt` دارد که فقط root می‌تواند بخواند.

فرمان `myteldesk doctor` سرویس و اجرای واقعی مدل CPU را بررسی می‌کند؛
این نتیجه، آزمون ثبت SIP، صدای دوطرفه یا VAD خودکار یک تماس ضبط‌شده نیست.
داخلی‌های معتبر SIP/WebRTC را جداگانه آماده کنید. نصب محیط VAD، سیاست ضبط
یا نگهداری موجود را به‌صورت خودکار فعال یا تغییر نمی‌دهد.

گزینهٔ `MYTELL_DESK_PUBLIC_URL=https://pbx.example.com` نشانی عمومی میز کار را
تعیین می‌کند؛ گواهی صادر نمی‌کند و ترانک نمی‌سازد. دادهٔ کشورها با ذکر منبع
DB-IP Country Lite و GeoNames استفاده می‌شود و دریافت آن به دسترسی منبع نیاز
دارد. در خطای دریافت یا تبدیل، دادهٔ معتبر قبلی حفظ می‌شود؛ قوانین فایروال
با به‌روزرسانی داده تغییر نمی‌کنند.

## ادامهٔ نصب و عیب‌یابی

پیش از اجرای دوباره، مطمئن شوید اجرای قبلی پایان یافته است. مراحل کامل و
شناخته‌شده فقط با **همان انتشار و هش بسته** قابل استفاده‌اند. چارچوب نیمه‌راه‌اندازی‌شده
یا وضعیت قدیمی، ناشناخته و متعلق به نسخهٔ دیگر ممکن است رد شود. وضعیت، رمزها
و گزارش را حفظ کنید؛ برای عبور از کنترل، نشانگرها را حذف یا تنظیمات را بازنشانی نکنید.

- گزارش نصب: `/var/log/mytelpbx-install.log`
- وضعیت سرویس‌ها: `systemctl status httpd mariadb asterisk myteldesk`
- خطای `bundle checksum mismatch`: دارایی و هش انتشار رسمی و شبکه را بررسی
  کنید؛ کنترل صحت را دور نزنید.
- خطای وجود PBX یا مالکیت منبع: نصاب پایه را متوقف کنید و نگهداری محدود را
  بررسی کنید. برای بازگشت واقعی به سیستم تازه از نصب مجدد سیستم‌عامل یا
  پشتیبان شناخته‌شده استفاده کنید.

پس از نصب موفق، یک راه‌اندازی مجدد برنامه‌ریزی‌شده پیشنهاد می‌شود.
`MYTELL_REBOOT=1` فقط پس از موفقیت بررسی‌ها و ذخیرهٔ رمزها درخواست reboot می‌دهد.
سلامت سرویس به‌تنهایی پذیرش کامل مرکز تماس نیست.

## شبکه و امنیت

| پورت | کاربرد |
|------|--------|
| ۲۲ | مدیریت SSH موجود؛ بدون تغییر |
| ۸۰/۴۴۳ TCP | پنل وب |
| ۵۰۶۰ TCP/UDP و ۵۰۶۱ TCP | سیگنالینگ SIP |
| ۱۰۰۰۰ تا ۲۰۰۰۰ UDP | صدای RTP |

firewalld فعال می‌ماند. این نصاب **SELinux را غیرفعال می‌کند** و از PHP 7.4
با پشتیبانی پایان‌یافتهٔ بالادستی استفاده می‌کند. دسترسی پنل را محدود و
اجزای پشتیبانی‌شدهٔ سیستم را به‌روز نگه دارید. هویت بسته‌ها و مخازن و اطلاعیه‌های
لازم حفظ می‌شوند؛ [اطلاعیهٔ اجزای نرم‌افزاری](../THIRD_PARTY_NOTICES.md) را ببینید.

فایل ISO یک خروجی محلی جداگانه است و در دارایی‌های انتشار گیت‌هاب بارگذاری
نمی‌شود. گزارش‌های قدیمی، تأیید نسخهٔ جاری نیستند؛ مبنا
[گزارش ۷٫۶٫۲](releases/7.6.2/verification.md) است.
