# وصله‌های میز کار — MyTellPBX

سورس میز کار جدا و با شناسهٔ قفل‌شده روی سرور در مسیر مستقر خودش
قرار دارد (تصمیم د۲). این پوشه وصله‌گرهای خودتوان پروژه است: هر
اسکریپت لنگرهای دقیق را وارسی می‌کند، از هر فایل یک‌بار بکاپ
می‌گیرد، اجرای دوباره بی‌اثر است و در نبود لنگرها با خطای غیرصفر
می‌ایستد.

## ترتیب اعمال (نسخهٔ ۷٫۲٫۰ به بعد)

همهٔ دستورها از ریشهٔ مخزن اجرا می‌شوند؛ فقط گام ساخت رابط به مسیر
پروژهٔ میز کار می‌رود و برمی‌گردد:

```bash
# ۱) نشانی تازه + ریدایرکت دائمی + هدایت پل
python3 modules/mytellpbxopdesk/patches/patch-desk-rename.py

# ۲) ورود با حساب پنل (پس‌زمینه + فرم + آزمون‌ها + ساخت پس‌زمینه)
python3 modules/mytellpbxopdesk/patches/patch-panel-login.py

# ۳) فارسی‌سازی پایه (اگر نصب تازه است)
cp modules/mytellpbxopdesk/patches/fa-translation.json \
   /opt/opdesk/frontend/src/i18n/locales/fa/translation.json
python3 modules/mytellpbxopdesk/patches/patch-fa-enable.py
python3 modules/mytellpbxopdesk/patches/patch-fa-notif.py

# ۴) ساخت رابط با پیشوند نشانی تازه
(cd /opt/opdesk/frontend && npx vite build --base=/MytellDesk/)

# ۵) قالب پنل (کارت ورود + منوی «ورود به میز کار») — از ریشهٔ مخزن
bash theme/install-theme.sh
```

## فهرست وصله‌گرها

- `patch-desk-rename.py` — بازنویسی پیکربندی آپاچی برای نشانی تازه
  با ریدایرکت دائمی از نشانی کهنه و به‌روزرسانی مقصد پل ورود.
- `patch-panel-login.py` — مسیر احراز هویت حساب پنل در پس‌زمینه
  (پایگاه پنل فقط‌خواندنی، نگاشت هویت یکتا، توکن ۱۵دقیقه‌ای با نشان
  منبع، بازبینی عضویت و نگهبان وب‌ساکت)، انتخابگر «حساب پنل/حساب
  میز کار» در فرم ورود، آزمون‌های واحد، ساخت و ری‌استارت سرویس.
- `fa-translation.json` + `patch-fa-enable.py` + `patch-fa-notif.py` —
  فارسی کامل رابط (۲۱۰۵ کلید) و پیش‌فرض‌سازی زبان.

## نکته‌های استقرار

- ساخت رابط حتماً با پیشوند نشانی تازه انجام شود؛ بدون پیشوند،
  مسیر داره‌ها مطلق می‌شود و صفحه خالی می‌ماند.
- رمز پل در فایل اختصاصی سرور با یکی از دو قالب پذیرفته می‌شود:
  «کلید=مقدار» یا گذرواژهٔ خام تک‌خطی.
- پس از وصلهٔ احراز پنل، جدول نگاشت هویت در پایگاه‌دادهٔ خود دسک
  ساخته می‌شود؛ پایگاه‌دادهٔ پنل همیشه فقط‌خواندنی می‌ماند.
- پراکسی وب‌ساکت سِس: `ProxyPass /sip-ws ws://127.0.0.1:8088/ws`
- اگر نام‌های کاربری فارسی با کاراکترهای به‌هم‌ریخته ذخیره شدند، با
  تبدیل دوکدگذاری‌برگشتی درست می‌شوند.
