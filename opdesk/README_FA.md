# اپدسک — گذرواژه‌ها و بازیابی دسترسی 🔑

هر کاربر اپدسک **دو گذرواژهٔ جداگانه** دارد؛ اشتباه‌گرفتن این دو، شایع‌ترین علت «وارد نمی‌شوم» است:

| | گذرواژهٔ ورود (Login) | گذرواژهٔ سِس (SIP) |
|---|---|---|
| کجاست | پایگاه‌دادهٔ OpDesk | مرکز تلفن (راز داخلی) |
| برای چه | ورود به صفحهٔ اپدسک | ثبت‌نام تلفن‌ها و نرم‌تلفن |
| از کجا عوض می‌شود | تنظیمات اپدسک → گذرواژهٔ ورود | تنظیمات اپدسک → گذرواژهٔ سِس، یا پنل ایزابل |
| تغییرش چه اثری دارد | فقط ورود به اپدسک | همهٔ تلفن‌های آن داخلی باید دوباره ثبت‌نام کنند |

💡 **عوض‌کردن گذرواژهٔ سِس، گذرواژهٔ ورود را عوض نمی‌کند** (و برعکس).

## ⚠️ سه علت شایع «وارد نمی‌شوم»

۱. **اشتباه‌گرفتن دو گذرواژه:** گذرواژهٔ سِسِ تازه را برای ورود می‌زنید؛ ورود گذرواژهٔ خودش را می‌خواهد.
۲. **قفل ضدجست‌وجوی گذرواژه:** بعد از ۱۰ ورودِ ناموفق در ۵ دقیقه، همان آی‌پی ۱۰ دقیقه قفل می‌شود (پیام «Too many failed login attempts»). صبر کنید یا سرویس را ری‌استارت کنید.
۳. **نا‌هماهنگی پل ورود پنل:** فایل `/etc/mytellpbx/opdesk-bridge.pw` باید همان گذرواژهٔ ورودِ کاربر `admin` باشد تا دکمهٔ اپدسک داخل پنل ایزابل کار کند.

## 🛠 ابزار بازیابی گذرواژهٔ ورود

روی سرور، به‌عنوان روت:

```
/usr/local/sbin/mytellpbx-opdesk-passwd <نام‌کاربری-یا-داخلی> <گذرواژهٔ-جدید>
systemctl restart mytellpbx-opdesk
```

نمونه (داخلی ۲):

```
mytellpbx-opdesk-passwd 2 'NewPass123$'
systemctl restart mytellpbx-opdesk
```

ری‌استارت، قفل ضدجست‌وجو را هم پاک می‌کند. گذرواژه با bcrypt (همان کتابخانهٔ خود اپدسک) هش می‌شود و هرگز در لاگ یا خط فرمانِ فرایندها ظاهر نمی‌شود.

اگر نام کاربری را نمی‌دانید، فهرست کاربران:

```
mysql -uroot -p"$(grep -oP '(?<=^mysqlrootpwd=).*' /etc/issabel.conf)" OpDesk \
  -e "SELECT id,username,extension,role FROM users;"
```

## 📦 نصب ابزار (برای نصب‌های قدیمی‌تر از 7.1.2)

فایل `reset-login.sh` همین پوشه را روی سرور بگذارید:

```
install -m 700 reset-login.sh /usr/local/sbin/mytellpbx-opdesk-passwd
```

پیش‌نیازها: بک‌اند اپدسک در `/opt/opdesk/backend` با `node_modules` (کتابخانهٔ bcryptjs خودش)، کلاینت mysql و دسترسی روت.
